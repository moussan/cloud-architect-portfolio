# Containerized Application Deployment on EKS

## 🌐 Overview
Deploying containerized workloads on Amazon EKS using:

- Managed node groups
- IRSA (IAM Roles for Service Accounts)
- AWS Load Balancer Controller
- Helm charts
- GitHub Actions CI/CD

## 🎯 Demonstrates
- How to deploy workloads on EKS
- Safe IAM integration via IRSA
- CI/CD → EKS workflow
- Ingress patterns
